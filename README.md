# 🏏 MS Dhoni Cricket Analytics Dashboard | Power BI

An interactive **Power BI dashboard** analyzing the international cricket career of **MS Dhoni**.

The dashboard provides insights into his batting performance, runs, innings, boundaries, strike rate, batting positions, opponents, grounds, dismissal types, and performance across different match formats.

## 📊 Dashboard Preview

![MS Dhoni Cricket Dashboard](Dashboard.png)

## 🔍 Key Insights

- 🏏 **Total Runs:** 17,266
- 📈 **Total Innings:** 612
- 6️⃣ **Total Sixes:** 359
- 4️⃣ **Total Fours:** 1,486
- ⚡ **Strike Rate:** 79.08
- 🏆 **Highest Score:** 224

## 📌 Dashboard Features

- Total Runs, Innings, Sixes and Fours
- Strike Rate and Highest Score
- Runs by Opposition
- Runs Over Time
- Runs by Ground
- Dismissal Type Analysis
- Performance by Match Type
- Batting Position vs Average Runs
- Total Fours and Sixes by Year
- Interactive filters for:
  - Match Type
  - Year
  - Opposition
  - Ground
  - Batting Position
